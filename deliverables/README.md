## 一、访问方式

服务已在本地跑起来：

```
http://127.0.0.1:8951          # 主页（功能展示优先）
http://127.0.0.1:8951/tech     # 技术细节子页
```

你自己用 cloudflared 暴露即可，例如：

```bash
cloudflared tunnel --url http://127.0.0.1:8951
```

> ⚠️ 服务绑定在 `127.0.0.1`（不是 `0.0.0.0`）。cloudflared 跑在同一台机器上时这样最安全；
> 若要让局域网其他设备直连，需把 `server.py` 末尾的 `host` 改成 `0.0.0.0` 并注意防火墙。

重启服务：

```bash
cd /Users/shihao/WorkBuddy/2026-09-26-23-35-42/verifin-site
/Users/shihao/WorkBuddy/2026-09-19-02-37-19/.venv/bin/python server.py
```

## 四、每个板块都配示意图/动图

原则：**动效只用于解释机制，不做装饰性炫技**；全部遵守 `prefers-reduced-motion`。

| 动画类 | 语义 | 用在 |
|---|---|---|
| `.flow-dash` | 数据在链路上流动 | 主页 Hero、技术页三张图的所有连接线（共 30 处） |
| `.sweep` | 高亮扫过（定位命中那一行） | 主页能力图、技术页 LOCATE 节点 |
| `.pulse-dot` | 候选汇聚脉冲 | 主页、技术页四路召回→RRF 的汇聚线（错峰 0.35s） |
| `.intercept` | 护栏拦截闪动 | 主页、技术页「程序级拒答」节点描边 |
| `.breathe` | 节点呼吸 | 主页、技术页 VERIFY_SPAN 核心校验节点 |
| `.balance-beam` / `.balance-ok` | 勾稽天平平衡 | 主页可信性区 |
| `.route-ok` / `.route-dim` | 合法后继亮起 / 死路变暗 | 技术页编排图分叉处 |
| `.scan-bar` | 文档解析扫光 | 预留（本期未挂载） |

> 实现注意：同一元素上「虚线流动」与「路由明暗」两个 `animation` 简写会互相覆盖，
> 已用组合写法 `.flow-dash.route-ok { animation: dashmove ..., routeOk ...; }` 并列声明。

## 七、历轮修掉的真实缺陷

1. **「核验」主按钮没绑 click 事件** —— `themeBtn` / `guardBtn` 都绑了，唯独主按钮漏了，
   点击毫无反应。已补，并顺带加了 `Ctrl/Cmd + Enter` 提交。
2. **窄屏下财务表格被裁 / 整页横向溢出** —— 根因是 `1fr` 网格轨道的隐式 `min-width:auto`
   被内容（`table.data{min-width:520px}`）顶住不放。已给 `.demo-grid > *` 与 `.result-area`
   置 `min-width:0`，滚动条正确落到 `.tbl-wrap` 上。390 视口溢出从 592px 归零。
3. **技术页示意图只用了 1 类动画，另 5 类闲置** —— 只画了流动线，"机制"没动起来。
   已把拦截/汇聚/呼吸/路由四类动画挂到对应语义位置。
4. **多处 SVG 文字排版问题**（getBBox 量化定位，非目测）：
   - 能力图 2「校验关卡」拒答框与输出框文字**完全重叠**（两个框 y=104/112 叠一起）
   - 天平图 18 位数字溢出秤盘（秤盘加宽至 150px、倾角 7°→5°）
   - 溯源图坐标串溢出 250px 卡片（拆两行）
   - 主页字号被缩放压到 8.4-9.5px 发虚（9/9.5/10 统一提一档）
5. **主页整块内容被一条 CSS 排坏** —— `.cap-points li` 用 `display:grid` 做"圆点+文字"两列，
   但 `li` 内容是「文本 + `<b>` + 文本」的混合内联节点，网格把**每一段文本和每个 `<b>`
   都当成独立网格项**，`<b>` 被塞进 20px 窄列竖排成 197px 高的条。
   改用 `display:block` + 绝对定位圆点后：`li` 盒高 233.8→50.8px、两列高比 2.27→1.07、
   章节高 3920→2263px、整页高 7291→5633px。
6. **chip 文案正则可与「利润表」不匹配**，导致一条 chip 显示整句、其余显示短科目名。
7. **窄面板里表格被挤成竖条** —— 勾稽面板 380px 下"值"列吃掉 205px，副标题折成 25px 竖条、
   单行撑到 394px。修后行高统一 71px、结果区 1036→447px。
8. **示意图在窄容器被压到读不出** —— 1024px 笔电下 10.5px 标注实际 8.4px、手机端 6.4px。
   已把能力区单列断点 900→1100px，并给示意图加尺寸上下限 + 横向滚动承接。
9. **浏览器强缓存旧 CSS** —— 会让访客发布后继续看到老版面。已在 `server.py` 加
   `Cache-Control: no-cache, must-revalidate` + `SITE_VERSION` 版本号注入；
   字体等二进制另给 `immutable` 长缓存（换字体需同步改名）。
10. **交付文档数字与实测漂开** —— 文档写"技术页 11 张 SVG / 视口 9/9"，实测 8 个 `<svg>`
   （3 图 + 5 图标）、11 档全通过。已按「内容图 / 图标」分列更正，并补暗色视口行。
